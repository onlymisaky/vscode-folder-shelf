# 文件夹书架 配置指南

收藏列表由一个 JSON 文件持久化，本指南描述全部配置项、合法取值与类型约束。

## 文件位置

- 默认：`~/.folder-shelf/config.json`
- 自定义：设置 `folderShelf.configFile`（支持 `~` 前缀指向主目录）
- 文件不存在时按空列表处理；执行「打开配置文件」等操作时会自动创建

## 顶层结构

| 配置项 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `items` | array | 可省略（省略视为空列表） | 收藏条目列表 |
| 其他字段 | 任意 | 无校验 | 自定义字段，写回时原样保留，不会被删除或改写 |

顶层必须是 JSON 对象；是数组或基础类型时视为结构错误。

## 条目（items 的每个元素）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `path` | string | **必填**，非空字符串（唯一强约束） | 文件夹/文件的本地路径 |
| `group` | string | 可选；其他类型显示为未分组 | 分组名，按首次出现顺序展示 |
| `tags` | string[] | 可选；非字符串元素仅不参与显示，不改写文件 | 标签列表，可多选筛选 |
| 其他字段 | 任意 | 无校验 | 自定义字段（如 `label`、`sort`），原样保留 |

`path` 的合法值范围：任意非空字符串。

- **本地绝对路径**（如 `/Users/you/projects/demo`）——推荐，可正常展示图标、子层级与存在性
- 相对路径、`~/...`、自定义 URI（如 `vscode-remote://...`）——允许登记，
  但无法按本地磁盘解析的条目会显示「条目在磁盘上不存在」占位

`path` 缺失、非字符串或空串的条目视为**无效条目**：不参与渲染，
树末尾显示「N 个无效条目」（悬停查看详情），写回时原样保留。

## 错误保护

- JSON 语法错误 / 顶层不是对象 / `items` 不是数组：弹窗提示错误类型与位置，
  且期间所有增删改被拒绝，**配置文件不会被覆盖**；修复并刷新后自动恢复
- 部分条目无效：不影响其余条目，仅追加「无效条目」提示节点

## 写回规则

- 增删改只改写命中的字段，不自动清洗任何内容
- 未知字段（顶层与条目级）、无效条目一律原样保留
- 对象键的书写顺序不保证与原文件一致（内容不变，仅顺序可能调整）

## 完整示例

```json
{
  "version": 3,
  "items": [
    {
      "path": "/Users/you/projects/demo",
      "group": "work",
      "tags": ["frontend", "main"],
      "otherField": { "anyKey": 1 }
    },
    {
      "path": "/Users/you/notes"
    }
  ]
}
```

示例中的 `version` 与 `otherField` 为自定义字段：可以随意增删，扩展不会动它们。
